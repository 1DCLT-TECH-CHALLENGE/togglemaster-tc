## Decisão

A Fase 3 continua em modo offline até aviso explícito.

Antes do Lab, seguem proibidos:

- `aws configure`;
- `aws sts get-caller-identity`;
- `terraform plan`;
- `terraform apply`;
- `terraform destroy`;
- `kubectl apply`;
- `helm install`;
- deploy real;
- criação de recurso AWS.

## Critério de transição

A transição para cloud só começa quando for declarado explicitamente:

`A partir daqui precisa abrir o AWS Academy Lab.`
