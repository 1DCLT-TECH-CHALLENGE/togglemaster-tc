# _shared — ToggleMaster TC

Área compartilhada do rebuild.

## Diretórios

- `scripts/`: helpers globais e validadores compartilhados.
- `evidencias/`: evidências consolidadas do rebuild.
- `logs/`: logs globais de execução.
- `tmp/`: arquivos temporários não versionáveis.

## Observações

Esta área não deve conter credenciais, tokens, tfstate, kubeconfig real ou arquivos sensíveis.
